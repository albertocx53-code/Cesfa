# CESFA Sistema Escolar

## Instalação

Abra o CMD na pasta do projeto:

pip install -r requirements.txt

## Executar

Clique em start.bat

ou rode:

python -m uvicorn main:app --reload

## Abrir

http://127.0.0.1:8000
